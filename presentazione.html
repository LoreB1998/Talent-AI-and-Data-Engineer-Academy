02 — AGENTE AI

Solo estrazione, non decisione

Microsoft Foundry, agente "PDF-Analyzer" — un compito unico e ben definito, non un tool-calling autonomo verso il gestionale.

ACOSA FA L'AGENTE

Legge il PDF, restituisce un JSON strutturato: dati cliente, riferimenti ordine, righe articolo. Un solo turno, nessuna chiamata a strumenti esterni. La classificazione del tipo documento (ordine / quotazione / richiesta info / non determinabile) è già inclusa nell'output.

JSON grezzo → validazione
PPERCHÉ NON TOOL-CALLING

Bug confermato di Foundry: l'agente che chiama tool OpenAPI verso Assets tramite agent_reference + responses.create restituisce sistematicamente 400 invalid_payload — riproducibile via API, assente nel Playground. Soluzione: tutta la validazione (matching cliente/articolo, controlli di coerenza) spostata in Python, con chiamate REST dirette ad Assets.

06 — SFIDE TECNICHE

Problemi reali, soluzioni verificate

Un ambiente Fabric/Foundry ancora giovane presenta limitazioni non documentate. Ogni blocco ha richiesto diagnosi e una soluzione concreta.

Date sempre NULL in Silver
to_date() Spark senza formato esplicito si aspetta yyyy-MM-dd; i PDF italiani usano dd/MM/yyyy e falliscono silenziosamente. try_to_date non disponibile in questo runtime. → UDF Python con datetime.strptime su più formati in sequenza.
%pip install disabilitato in Pipeline
Le magic command non sono supportate nelle esecuzioni non interattive triggerate da Pipeline (MagicUsageError). → Fabric Environment custom con azure-ai-projects e azure-identity preinstallate via PyPI, pubblicato e collegato al notebook.
DefaultAzureCredential non funziona in Spark Fabric
Nessun az login interattivo disponibile in un Notebook Spark. → Classe TokenStaticoCredential, wrapper che implementa TokenCredential restituendo un token Azure AD generato manualmente.
Upload PDF: path OneLake non risolto da mount point
getMountPath gestisce mount point espliciti, non path OneLake generici. → mssparkutils.fs.cp() verso il filesystem locale del driver, poi open() Python standard.
File ID con prefisso errato dopo upload
Comportamento intermittente del backend Foundry: a volte l'ID torna con prefisso file- invece di assistant-, non utilizzabile dall'agente. → Retry sull'upload finché il prefisso è corretto.
Workspace Identity non configurabile come Managed Identity
Limitazioni IAM sul tenant del corso impediscono l'uso della Workspace Identity nativa di Fabric per l'autenticazione verso Foundry. → Token statico rigenerato manualmente (~1h di validità), soluzione pragmatica per l'ambito del progetto.
07 — RISULTATO

Cosa è stato costruito

Quattro percorsi di classificazione, un'architettura a tre notebook, un modello analitico unificato.

Ordine

Validazione cliente e articoli vs catalogo, verifica prezzo e unità di misura, flag intervento umano.

Quotazione

Bozza di offerta con prezzi calcolati automaticamente dal listino ufficiale Assets.

Richiesta info

Ricerca articoli nel catalogo e generazione bozza di risposta da inoltrare all'operatore.

Non determinabile

Documenti ambigui o non leggibili → flag intervento_umano_necessario = true, archiviati in silver_documenti_non_gestiti per revisione manuale.
